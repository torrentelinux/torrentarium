::Instrucciones de uso::

[*] Primero tiene que iniciar el servidor Laragon presionando el botón 'Iniciar todo'.
[*] Luego tiene que iniciar el servidor GlassFish desde el entorno de NetBeans.
[*] Presione las teclas Ctrl+5 para entrar a la pestaña 'Services'.
[*] Haga clic derecho encima de 'GlassFish Server' y presione en opción 'Start'.
[*] Inicie y abra el navegador web de su preferencia.
[*] Escriba en la barra de direcciones la siguiente URL:
    http://localhost:8080/SlideShowApp/

Y mostrará las imágenes gráficas en el navegador web, éstas están en el directorio web/imagenes/
Usted puede poner allí cualquier imágen gráfica y cantidad que desee.
Los formatos reconocidos son: jpg, png y webp.
Atención:
    1] Instale GlassFish 8.0.0 mediante la asistencia de NetBeans, apartado Tools/Servers/Add Server...
    2]  El archivo 'guiapractica.php' tiene que estar alojado en el directorio 'c:\laragon\www\'
	 para que sea accedido mediante Apache HTTPD.
	 La URL que se utilizará es http://localhost/guiapractica.php

[*] Administración del servidor de aplicaciones desde 'Command Prompt' (cmd.exe)
	Para iniciar Eclipse GlassFish: glassfish\bin\asadmin start-domain
	Visite http://localhost:4848
	Para detener Eclipse GlassFish: glassfish\bin\asadmin stop-domain

Para mayor información sobre el uso de:
	· Eclipse GlassFish, visite el sitio https://github.com/eclipse-ee4j/glassfish
	· Laragon, visite el sitio https://github.com/leokhoa/laragon
