El programa "hay-red" es un script para Bash.
Comprueba que su computadora tenga conexion de red hacia el exterior (internet).
Se apoya en los siguientes programas: ping, nmcli, ip, curl y timedatectl.
No es necesario usar el comando 'sudo' para ejecutar este programa.
  
Ha sido probado en:
* Oracle Linux Server 7.9 y versiones posteriores.
* MX-Linux 23 y versiones posteriores.
* GobMis GNU/Linux 5.0 - Yetapa.

Descargue el archivo mencionado y luego asigne permisos de ejecucion (0775).
Puede guardarlo en algun directorio 'bin', por ejemplo en '~/bin'.
Ejecute asi en una consola de textos: ./hay-red
